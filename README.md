# PLUTO_BLARE
This is an Alarm Clock

How to change settings:

- Press `1` twice: set the clock
- Press `2` twice: change the password
- In clock setting, enter six digits as `HHMMSS`
- In clock setting, keypad `9` represents zero
- Press `8` to save a clock setting
- Press `7` to cancel
- To change the password, enter the current four-digit password, then the new four-digit password
- Press `1`–`5` to select an alarm
- Press `6` or `7` to change its hour
- Press `8` or `9` to change its minutes
- Press `5` to finish editing an alarm
- Press `9` outside the menus to toggle all alarms on or off
